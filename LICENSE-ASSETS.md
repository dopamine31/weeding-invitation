# Lisensi aset

- **Ornamen, ilustrasi foto, ikon, pola (kawung, bintang, tekstur kertas):** dibuat sendiri sebagai SVG/CSS di repo ini.
- **Musik:** tidak ada file audio. Musik latar dibangkitkan WebAudio secara prosedural.
- **Font** (diunduh dan di-host sendiri saat build lewat `next/font/google`), seluruhnya berlisensi **SIL Open Font License 1.1**: Playfair Display, Inter, Cormorant Garamond, Cormorant SC, DM Serif Display, DM Sans, Jost, Pinyon Script, Amiri, Lora, Caveat, Amatic SC, Anton, Cinzel.
- **Pustaka:** lihat `package.json` (MIT/Apache-2.0/ISC umumnya).
